# TuneScribe Project Plan

See the full implementation plan in `.cursor/plans/tunescribe_mvp_plan_e812db44.plan.md`.

This MVP focuses on:

1. Local FastAPI backend with Basic Pitch transcription
2. MIDI → MusicXML conversion via music21
3. Expo mobile app for recording, upload, and local project storage
4. Sheet music preview via OpenSheetMusicDisplay WebView

Long-term features (auth, cloud sync, arrangements, chord detection) are out of scope for the first iteration.
